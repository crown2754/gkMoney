# 功能規格：解決 AppServiceProvider 重複宣告 `boot` 方法問題

## 背景
Laravel 專案在執行 `php artisan serve` 時，於 `AppServiceProvider.php` 第 20 行報錯 `Cannot redeclare App\Providers\AppServiceProvider::boot()`，此問題通常由以下原因導致：

### 檢查清單
1. **重複檔案匯入**：同一檔案可能被多次匯入（例如 `composer.json` 重複包含相同檔案）。
2. **共用套件覆蓋**：第三方套件可能已定義 `boot` 方法，導致與自訂內容衝突。
3. **多段式執行**：`php artisan vendor:publish` 或自動載入機制錯誤。

## 解決方案
### 1. 檢查檔案結構
- 確認 `app/Providers/AppServiceProvider.php` 未被複製到 `vendor/` 或 `config/` 等目錄。
- 檢查 `composer.json` 的 `autoload` 區塊，避免重複載入。

### 2. 驗證 `boot` 方法定義
- 打開 `app/Providers/AppServiceProvider.php`，確認 `boot` 方法未被重複定義或繼承自第三方套件。
- 檢查是否有 `__construct` 或 `register` 方法錯誤呼叫 `boot`。

### 3. 清除暫存檔與重構
- 執行 `composer dump-autoload` 重構 autoload。
- 檢查 `bootstrap/cache/services.php` 是否異常（需備份後清理）。

## 需檢核的檔案
| 檔案路徑 | 檢查內容 |
|----------|----------|
| `app/Providers/AppServiceProvider.php` | 確認 `boot` 方法唯一定義 |
| `composer.json` | 檢查 `autoload` 區塊重複載入 |
| `vendor/` | 確認無專案檔案被誤放置 |
