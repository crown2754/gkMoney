# 銀行帳戶功能總規格

## 目標
在現有記帳/理財系統新增「銀行帳戶」功能，使使用者能管理多家銀行多幣別帳戶，系統自動以當日匯率計算台幣等值，並將所有帳戶的台幣餘額彙總顯示於首頁儀表板。

## 技術棧
- Laravel 11 + PostgreSQL + TALL (Tailwind + Alpine.js + Livewire + Laravel)
- `users.id` 為 `bigint`，所有外鍵使用 `foreignId()`

## 資料庫
- `banks`、`currencies`、`exchange_rates`、`bank_accounts`、`asset_snapshots`

## 服務層
- `ExchangeRateService`：抓取、快取、手動更新匯率
- `BankAccountService`：帳戶 CRUD、重新計算 `balance_twd`
- `AssetSnapshotService`：每日總資產快照

## 觀測器與政策
- `BankAccountObserver`：`created`/`updated`/`saved` 時重新計算
- `BankAccountPolicy`：僅擁有者可操作
- `ExchangeRatePolicy`：僅管理員可編輯

## Livewire 元件
- `BankAccountForm`、`BankAccountList`、`DashboardAsset`、`ExchangeRateForm`

## 排程
- `exchange:fetch-today-rates` 每日 00:30
- `asset:snapshot` 每日 01:00

## 驗收條件
1. 帳戶 CRUD 即時生效
2. `balance_twd` 自動計算
3. 首頁總資產正確
4. 每日匯率寫入
5. 資產快照正確
6. 權限隔離
7. 銀行下拉選單
8. 幣別下拉選單
9. 金額格式統一
10. 匯率失效容錯
