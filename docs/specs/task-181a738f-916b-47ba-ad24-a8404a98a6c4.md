# 銀行帳戶功能總規格

## 目標
在現有記帳/理財系統中新增「銀行帳戶」功能，使使用者能管理多家銀行的多幣別帳戶，系統自動以當日匯率計算台幣等值，並將所有帳戶的台幣餘額彙總顯示在首頁儀表板。

## 技術棧
- Laravel 11 + PostgreSQL + TALL (Tailwind + Alpine.js + Livewire + Laravel)
- `users.id` 為 `bigint`，所有外鍵使用 `foreignId()`

## 資料庫結構
| 表格 | 關鍵欄位 |
|------|----------|
| `banks` | `code` (string 3), `name` (string), `is_active` (boolean) |
| `currencies` | `code` (string 3), `name` (string), `is_active` (boolean) |
| `exchange_rates` | `currency_id` (bigInteger), `rate_to_twd` (decimal 15,6), `date` (date) |
| `bank_accounts` | `user_id` (bigInteger), `bank_id` (bigInteger), `currency_id` (bigInteger), `alias` (string), `account_number` (string), `balance` (decimal 15,2), `balance_twd` (decimal 15,2), `is_active` (boolean) |
| `asset_snapshots` | `user_id` (bigInteger), `total_twd` (decimal 15,2), `snapshot_date` (date) |

## 服務層
- `ExchangeRateService`：抓取、快取、手動更新匯率
- `BankAccountService`：帳戶 CRUD、重新計算 `balance_twd`
- `AssetSnapshotService`：每日產生總資產快照

## 觀測器與政策
- `BankAccountObserver`：在 `created`/`updated`/`saved` 時重新計算
- `BankAccountPolicy`：檢查 `user_id`
- `ExchangeRatePolicy`：僅允許 `is_admin`

## Livewire 元件
- `BankAccountForm`（新增/編輯）
- `BankAccountList`（表格顯示）
- `DashboardAsset`（首頁小元件）
- `ExchangeRateForm`（管理員匯率編輯）

## 排程
- `exchange:fetch-today-rates` 每日 00:30
- `asset:snapshot` 每日 01:00

## 測試覆蓋率目標
≥ 80%
